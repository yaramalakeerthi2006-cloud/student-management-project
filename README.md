 Student Management System

1.About the Project
The Student Management System is a web-based application developed using HTML, CSS, and JavaScript. It helps users manage student records easily through a simple and user-friendly interface.

Users can add, view, update, delete, search, and filter student information. The application also provides student statistics and CSV export functionality.

2.Features
- Add Students:Add student details such as ID, name, email, course, marks, and attendance.
- View Records:Display all student records in a table.
- Edit Students:Update existing student information.
- Delete Students:Remove student records.
- Search Students:Search using student ID, name, or email.
- Filter by Course:Filter records based on the selected course.
- Student Statistics:View total students, average marks, passed students, and total courses.
- Pass Status:Automatically displays student status based on marks (40 or above is considered a pass).
- Export CSV:Download student records as a CSV file.
- Local Storage:Save student records in the browser so they remain available after refreshing the page.
- Responsive Design:** Works on desktop and mobile screens.
 
4.Technologies Used
- HTML5 – Structure of the application.
- CSS3 – Styling and responsive design.
- JavaScript – Functionality and DOM manipulation.
- Browser Local Storage – Storing student records.

6.How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `student.html` file.
4. Open it in your web browser.
5. Start adding and managing student records.

No additional installation or dependencies are required.
